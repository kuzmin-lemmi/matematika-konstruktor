# Новые форматы материалов — предложения для ядра

Сейчас каждый материал — три режима: доска (показ по шагам), раздатка (кодовое слово, бланк ОГЭ), тренажёр.
Это закрывает объяснение, закрепление и ДЗ. У урока есть и другие моменты, где учителю нужна помощь:
начало урока, проверка в конце, групповая работа, повторение перед контрольной.

Главная мысль: **новые форматы — модули ядра, которые берут те же `TYPES` темы**. Тогда каждая тема получает
их без нового содержания: генератор, ответ (`ans`, `keyHTML`), ловушки (`traps`), объяснения (`wrong`) уже есть.
Новое содержание нужно только двум форматам («Найди ошибку» и раскраска) — им нужны необязательные поля.

Условия те же, что у сайта: компьютерного класса нет, телефоны ученикам на уроке нельзя, один экран и бумага.
Всё работает из одного HTML-файла, с флешки, без сервера.

на каждом уроке, «Своя игра» — раз в четверть.

## Общие правила для всех новых форматов

- **Номер = зерно.** Как у раздатки: по номеру листа восстанавливаются задания и ключ. Зерна новых форматов —
  в своих диапазонах `taskRnd(num, …)`, чтобы не задеть варианты раздатки (сейчас раздатка — 0…99, ОГЭ — 200+;
  предлагаю: билет 300+, самостоятельная 400+, тримино/домино/лото 500+, диктант 600+, разминка 700+).
- **Версии.** Состав каждого формата — константа с версией (`EXIT_V1`, `TEST_V1`…), как `KINDS_V1`.
  Опубликованный состав не меняется; тест снимка замораживает первые варианты каждого формата.
- **Адрес.** Печатные — новые значения `kind` в раздатке: `?mode=print&kind=exit`, `kind=test`, `kind=trimino`…
  Доска — новые значения `mode` или параметр `?mode=board&show=warmup`. Карточка на сайте перечисляет их
  в `sheets` (уже есть) и новом `boards` — так кнопки появятся в каталоге и плане уроков.
- **Ответы различаются.** Где ответы видны вместе (тримино, домино, лото, кодовое слово), генератор
  перегенерирует задание при совпадении ответа с уже взятым — как сейчас в `makeVariant`.
- **Печать.** A4, чёрным по белому, линии разреза пунктиром с ножницами ✂, ключ отдельной страницей.
- **Тест-контракт.** Для каждого формата: открывается без ошибок, один номер — один лист, ключ совпадает
  с `ans`, ответы в наборе различны, лист помещается на A4 (по модели раскладки, а не по DOM).

## Бумага

### Билет на выход (`kind=exit`) ★★★

Две-три задачи на четверть листа, четыре билета на A4. Раздаётся за 5 минут до звонка, учитель за минуту видит,
кто понял тему. Номер билета, ключ — строка на билет.

- Состав: `EXIT_V1` в теме или по умолчанию — первые три типа из `KINDS_V1` с формой попроще.
- Ответ — в рамке на билете («Ответ: ____»), без места для решения: решают в тетради или на обороте.
- Ключ: одна страница, «номер — три ответа».

### Самостоятельная и контрольная (`kind=test`) ★★★

Самое ценное для учителя — экономия вечера. Варианты I и II (или 4 варианта), задания по нарастанию
сложности, место для решения, **критерии оценки** внизу ключа.

```js
const TEST_V1 = {
  parts: [['sum', 'easy'], ['sum'], ['eq'], ['est', 'hard']],   // задания по порядку
  points: [1, 1, 2, 2],                                          // баллы за задание
  grades: { 5: 6, 4: 4, 3: 2 },                                  // «5» — от 6 баллов и т. д.
};
```

- Варианты I/II — соседние номера одной «пары», чтобы соседи по парте решали разное.
- Ключ: ответы по вариантам + шкала оценок. По желанию — полное решение (`ok(t)` уже даёт короткое объяснение).

### Тримино (`kind=trimino`) ★★☆

Головоломка: 9 или 16 треугольников, на стороне — задание, на соседней стороне другого треугольника — его ответ.
Собранные правильно, треугольники складываются в большой треугольник. Внешние стороны — ловушки из `traps`
(неверные ответы, которые не к чему приложить).

- Модель: большой треугольник из n² маленьких; внутренние рёбра — пары «задание/ответ», внешние — ловушки.
  Генерация: взять столько заданий, сколько внутренних рёбер, ответы различны; перемешать и повернуть
  треугольники по зерну.
- Печать: лист для разрезания (треугольники в случайном порядке и поворотах) и ключ — собранная фигура.
- Для 5–6 класса — 9 треугольников, для 7–9 — 16.

### Домино и лото (`kind=domino`, `kind=loto`) ★★☆

- **Домино:** 12–16 костяшек «ответ | задание», цепочка замыкается в кольцо. Проверка: цепочка сошлась.
- **Лото:** карта 3×3 с ответами у каждой группы (разные карты по номеру) и общая стопка карточек-заданий.
- Обе собираются из `text` и `keyHTML`; ловушки из `traps` — лишние ответы на картах лото.

### Двойник домашней работы (`kind=twin`) ★★☆

Проверочная на 5–7 минут в начале урока: те же типы, что были в тренажёре дома, другие числа.
Учитель выбирает раздел тренажёра (`SECTIONS`) — лист собирается из его типов. Защищает от списанного ДЗ.

### Опорный конспект (`kind=summary`) ★☆☆

Лист в тетрадь: правило (из `help.html`), образец решения (одно задание с `ok(t)`), блок «Так не делай» —
типичные ошибки из `CATS` с примером ловушки из `traps`. Полстраницы A4, две копии на листе.

### Раскраска по ответам (`kind=color`) ★☆☆

Для 5–6 класса: верные ответы дают номера цветов, раскрашенные области складываются в картинку.
Нужна библиотека картинок-шаблонов (области SVG с номерами) в ядре — это большая работа; отложить.

## Доска

### Разминка — устный счёт по теме (`show=warmup`) ★★★

Начало урока: 5–8 заданий по одному на экране, крупно, с таймером на задание (настройка в `CONFIG`),
ученики пишут ответы в тетрадь. В конце — все ответы списком для самопроверки. Каждый урок — новые числа.

- Нужен флаг `oral: true` у типов, которые решаются в уме (не всякий тип годится для устного счёта).
- Таймер здесь — часть упражнения, это не противоречит правилу «темп задаёт учитель».
- Это то, ради чего учитель будет открывать сайт каждый день.

### «Найди ошибку» (`show=errors` и `kind=errors`) ★★☆

На экране готовое решение по шагам, в одном шаге — типичная ошибка. Класс ищет шаг и объясняет.
Ошибки — те же, что ловушки (`traps`) и объяснения (`wrong`), то есть методика уже есть в каждой теме.

```js
// у типа задания — решение по шагам и «испорченное» решение для ловушки
steps: t => ['2/3 + 3/4', '= 8/12 + 9/12', '= 17/12', '= 1 5/12'],
mistake: (t, trap) => ({ at: 1, line: '= 5/7', why: 'сложили числители и знаменатели' }),
```

Печатная версия — 4–6 решений на листе, задание «найди и исправь ошибку», ключ — номер шага и верная строка.

### Математический диктант (`show=dictation`) ★★☆

Задания по одному с паузой (учитель листает или включает таймер), в конце — ответы. К нему — печатный бланк
с клетками для ответов (`kind=dictation`), номер бланка = номер варианта, если учитель хочет разные варианты
по рядам.

### «Верно — неверно» (`show=truefalse`) ★★☆

На экране утверждение «задание = ответ»: верный ответ или ловушка из `traps`. Класс поднимает карточку
(зелёная — верно, красная — неверно); после показа — объяснение из `wrong`. Комплект сигнальных карточек
печатается один раз на класс — это лист ядра, не темы.

### «Своя игра» / бой по рядам (`show=quiz`) ★☆☆

Таблица «раздел × стоимость» (разделы — `SECTIONS`, стоимость — сложность формы), счёт 2–4 команд на экране,
вопрос → ответ команды → учитель отмечает. Для повторения перед контрольной; можно собирать из нескольких тем,
но это уже не модуль темы, а отдельная страница сайта.

## Как это показать на сайте

- Режимов на сайте остаётся три — **доска, бумага, дом**, — а форматы становятся вариантами внутри:
  доска → «Показ», «Разминка», «Диктант», «Верно — неверно», «Найди ошибку»;
  бумага → «Раздатка», «Бланк ОГЭ», «Билет на выход», «Самостоятельная», «Тримино», «Домино», «Лото», «Конспект»;
  дом → тренажёр и «Ссылка для дома».
- В карточке: `sheets` (печатные виды, уже есть) и новое `boards` (виды показа на доске).
- В плане уроков у темы — три главные кнопки и «ещё ▾» со всеми форматами, чтобы строка не разрасталась.
- В каталоге — фильтр по этапу урока: «Начало урока», «Объяснение», «Групповая работа», «Проверка».

## Порядок, который я предлагаю

1. **Разминка** и **билет на выход** — малые усилия, пользоваться будут почти каждый урок.
2. **Самостоятельная с критериями** — самая большая экономия времени учителя.
3. **Тримино** и **домино** — живая групповая работа на бумаге, хорошо показывает, что сайт не только про экран.
4. **«Найди ошибку»** — когда у тем появятся `steps(t)`; начать с новых тем.
5. Остальное — по отзывам коллег на пилоте.

Отдельно от конструктора — **инструменты для доски** (таймер, «кто отвечает», клетка, числовая прямая,
координатная плоскость, транспортир): они не зависят от темы и делаются на сайте отдельной страницей.
