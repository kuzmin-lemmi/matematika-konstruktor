# AGENTS.md — конструктор материалов «Матшага»

Этот файл читают ИИ-агенты перед работой в папке конструктора. Пиши по-русски: ответы, комментарии,
тексты интерфейса, сообщения коммитов (повелительное наклонение: «Добавь тему …»).

## Что это

Конструктор собирает материалы сайта matshag.ru (математика 5–9 классов, проект «Матшаг»): общее ядро `core/`
+ тема `materials/<slug>/` → один самодостаточный HTML в `public/materials/<slug>.html` сайта.
Сайт — отдельный репозиторий (путь в `constructor.config.json`), его правила — в `AGENTS.md` сайта; правила
содержания материалов (запись, методика, печать, тесты) действуют и здесь.

- Как пользоваться — `ИНСТРУКЦИЯ.md`.
- Как делать новый материал — навык `.claude/skills/novyi-material/SKILL.md` (читай его при любой работе с темами).

## Структура

```
core/          ядро: page.html (разметка), base.css, shell.js, math.js, types.js, print.js, board.js, home.js, boot.js
materials/     темы: material.json, topic.js, help.html, topic.css
templates/new-material/   заготовка темы, карточки и теста сайта (npm run new)
tools/         build.mjs, new.mjs, snapshot.mjs, load.mjs, paths.mjs
tests/         contract.test.mjs (все темы), snapshot.test.mjs (замороженные варианты), snapshots/
```

## Команды

```bash
npm install
npm run new -- <slug> --title "Название"   # заготовка темы + карточка и тест на сайте
npm run build -- <slug>                     # собрать в сайт; --all — все темы; --site <папка> — другой сайт
npm test                                    # тест-контракт и снимки — перед любым «готово»
npm run snapshot -- <slug>                  # заморозить варианты опубликованной темы
```

## Правила

- Собранные файлы на сайте руками не правим — правим тему или ядро и пересобираем.
- Варианты опубликованных тем не меняем: тест снимка должен проходить. Изменение генератора — только с новой
  `GEN_VERSION` и сохранением старой ветки (см. `ИНСТРУКЦИЯ.md`, раздел 5).
- Изменил ядро — `npm run build -- --all`, `npm test`, тесты сайта (`npm test` в папке сайта).
- Самодостаточный HTML: без библиотек и запросов к другим сайтам (кроме Google Fonts), `localStorage` — в `try/catch`.
- Зависимости — только для проверок (jsdom). Сервер, аналитика, внешние сервисы — только по решению автора.
