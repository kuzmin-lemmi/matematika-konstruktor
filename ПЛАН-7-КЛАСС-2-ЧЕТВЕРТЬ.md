# План разработки: 7 класс, вторая четверть

Дата: 28 октября 2026. Цель: к началу второй четверти закрыть все темы 7 класса (алгебра, уроки 25–48;
геометрия, уроки 17–32) набором материалов, подобранных под характер каждой темы, а не тремя режимами подряд.

Границы четверти взяты из плана сайта (`src/data/lesson-plans.json`, `quarterEnds`) и ориентировочны —
сверить с КТП автора. Оценки трудоёмкости — ориентиры, их нужно уточнять по факту первой темы.

## Принципы

1. Формат выбирается по теме: алгоритм — раздатка и тренажёр; понятия — конспект, «верно — неверно», диктант;
   геометрия — живая доска.
2. Ядро расширяем только тем, что нужно сразу нескольким темам. Тематическое остаётся в теме.
3. Порядок — по урокам четверти: то, что нужно раньше, делается раньше.
4. Публикуем только после явного «одобряю, публикуй» автора на каждый материал (AGENTS.md, шаг 4).
5. Каждый материал: независимый тест на сайте, `npm run check`, просмотр глазами (доска, печать, телефон).

## Этап 1. Ядро: общие форматы (2–3 сессии)

Делаем то, что нужно нескольким темам. Порядок по пользе (из `claude/novye-formaty`):

| № | Формат | Нужен темам | Что от темы |
|---|---|---|---|
| 1.1 | Билет на выход (`kind=exit`) | почти всем | ничего, берёт `KINDS_V1` |
| 1.2 | Разминка — устный счёт (`show=warmup`) | алгебра 25–34, 42–48 | флаг `oral` у простых типов |
| 1.3 | «Найди ошибку» (`show=errors`, `kind=errors`) | формулы, разложение, многочлены | `steps(t)` у типов |
| 1.4 | «Верно — неверно» (`show=truefalse`) | многочлены, равнобедренный треугольник | список утверждений темы |
| 1.5 | Математический диктант (`show=dictation`) | понятийные темы | ничего |
| 1.6 | Самостоятельная (`kind=test`) | конец блока | необязательный `TEST_V1` |
| 1.7 | Домино / тримино (`kind=domino`, `kind=trimino`) | разложение на множители | ничего |

Что обязательно для каждого формата (общие правила из предложения):
- работает без `localStorage`, на A4 и в «два варианта на листе»;
- один номер варианта даёт один и тот же лист; старые варианты опубликованных тем не меняются
  (снимок, `GEN_VERSION`);
- контракт-тест `tests/contract.test.mjs` проверяет его для всех тем;
- выключенный формат не ломает темы, где он не нужен.

Готово, когда: формат подключается темой без копирования каркаса, `npm run build -- --all` и `npm test`
проходят, хотя бы одна опубликованная тема получила его без смены вариантов.

Порядок внутри этапа: 1.1 → 1.2 → 1.3 первыми (они закрывают больше всего уроков); 1.4–1.7 — по мере нужды темы.
