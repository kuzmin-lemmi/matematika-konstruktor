# Быстрая проверка темы

`npm run check:fast -- <slug>` проверяет сборку в памяти и контракт только выбранной темы. Сайт, постеры и Git не меняются. Полный `npm run check -- <slug>` перед показом остаётся обязательным.

Если npm недоступен: `node tools/check-fast.mjs <slug>`.

Для независимой проверки добавь в тему `expected.mjs` с экспортом `expected(task)`. Функция получает копию данных задания и возвращает `{ value, key }`: значение для поля ответа и строку ключа. Она должна самостоятельно решать задачу, не импортировать вычислитель материала. Неизвестный тип должен вызывать ошибку.

Механизм проверяет 200 отдельных зёрен каждого типа и 30 вариантов кодового слова. Ошибки содержат тип, зерно или номер варианта и данные задания. Другие форматы, специальные ошибки и математические свойства по-прежнему проверяются тематическими тестами сайта.

Без expected.mjs быстрый запуск явно сообщает, что независимая математика не проверена. Старые тесты сайта сохраняются. Общий механизм доступен как `checkIndependent(APP, expected)` из tools/independent.mjs; образец использования — tests/independent.test.mjs.
