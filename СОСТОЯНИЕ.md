## Окружение и оставшиеся задачи

`gh auth status` не видит вход на этом компьютере. Для чтения и работы с PR доступен подключённый GitHub;
команда публикации материала по-прежнему требует отдельной авторизации gh.
Проверка Astro выполнялась с ASTRO_TELEMETRY_DISABLED=1 в окружении процесса.
Для штатного check использовался запуск от владельца репозитория: Git в песочнице блокировал другую учётную запись.
Глобальные настройки Git и авторизации в рамках этапа не изменялись.

Следующая задача конструктора — этап 2 плана: снимки разных версий, защита от перезаписи,
изоляция старых генераторов и CI. Реестр версий уже есть, но текущая автоматическая проверка снимков
ещё не обеспечивает полный переход на версию 2. Развитие живой доски — следующий отдельный этап.
