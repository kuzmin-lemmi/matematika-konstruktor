# Конструктор материалов «Матшага»

Конструктор собирает материал для сайта matshag.ru из двух частей:

- **ядро** (`core/`) — всё, что одинаково во всех материалах: стартовый экран, доска с шагами «вопрос → показ»,
  раздатка с кодовым словом и бланком ОГЭ, ключ по номеру варианта, печать A4, тренажёр с очками, подсказками
  и итогами «Над чем поработать», тёмная тема, ссылка для учеников;
- **тема** (`materials/<slug>/`) — только содержание: какие задания, как их проверять и объяснять ошибки,
  шаги показа на доске, справка.

Сборка склеивает их в **один самодостаточный HTML-файл** и кладёт его в сайт: `public/materials/<slug>.html`.
Для учителя ничего не меняется — тот же файл, работает с флешки, адреса страниц прежние.

Новый материал — это 300–700 строк содержания вместо 1500 строк каркаса. Улучшение ядра (новый вид листа,
исправление вёрстки) получают все материалы после пересборки.

---

## 1. Подготовка (один раз)

Нужен Node.js 22.13 или новее (уже стоит для сайта).

```bash
cd "D:\Конструктор математика"
npm install
```

Путь к сайту записан в `constructor.config.json`:

```json
{ "site": "C:/Users/admin/Desktop/matematika" }
```

Если сайт лежит в другом месте, поменяй путь здесь. На один запуск — флаг `--site <папка сайта>`.

## 2. Как сделать новый материал

### Проще всего — попросить ИИ

Открой папку конструктора в Claude Code (или другом агенте) и напиши, например:

> Сделай в конструкторе материал «Свойства арифметического квадратного корня», 8 класс, Макарычев:
> корень из произведения и дроби, вынесение и внесение множителя. Все три режима и бланк ОГЭ.

У ИИ есть навык «Новый материал» (`.claude/skills/novyi-material/SKILL.md`) — порядок работы, требования
и список ловушек, на которые мы уже наступали. Он сделает заготовку, наполнит тему, прогонит проверки
и подготовит публикацию. Тебе остаётся посмотреть материал и сказать «отправляй на сайт».

### Вручную, по шагам

1. **Заготовка.** В папке конструктора:

   ```bash
   npm run new -- slozhenie-drobei --title "Сложение дробей с разными знаменателями"
   ```

   slug — транслит названия латиницей через дефис. После публикации slug не меняется: на него ведут
   раздатки и ссылки в чатах классов.

   Команда создаст:
   - `materials/<slug>/material.json`, `topic.js`, `help.html` — тему с рабочим примером
     (сложение чисел с разными знаками), которая сразу собирается и проходит проверки;
   - на сайте — карточку `src/content/items/<slug>.md` с `access: soon` (материал ещё не виден учителям)
     и черновик теста `tests/<slug>.test.mjs`;
   - собранный файл `public/materials/<slug>.html`.

2. **Наполнить тему.** Заменить всё, что помечено «ЗАМЕНИ» (раздел 3 ниже — что где).

3. **Собрать и проверить:**

   ```bash
   npm run build -- <slug>    # собрать в сайт
   npm test                   # тест-контракт конструктора: все темы, все режимы
   ```

   Посмотреть материал: открыть `public/materials/<slug>.html` в браузере или запустить сайт
   (`npm run dev` в папке сайта) и открыть `http://localhost:4321/zapusk/<slug>/`.

4. **На сайте** (в папке сайта):
   - дописать в `tests/<slug>.test.mjs` независимое решение заданий и прогнать `npm test`;
   - снять картинку-превью: `npm run posters <slug>`;
   - заполнить карточку: `access: free`, `added`, `poster`, описание по абзацу на режим; если есть бланк ОГЭ —
     `sheets: - { kind: oge, label: "Бланк ОГЭ" }`;
   - `npm run validate` — проверки, тесты, сборка сайта;
   - закоммитить и опубликовать (или сказать ИИ «отправь на сайт»).

## 3. Из чего состоит тема

```
materials/<slug>/
  material.json   тексты страницы: название, описание, подписи режимов, заголовки
  topic.js        содержание: параметры, типы заданий, разделы тренажёра, раздатка, доска
  help.html       справка в тренажёре (формулировки как в учебнике)
  topic.css       необязательно: стили, нужные только этой теме
```

### material.json

| Поле | Что это |
|---|---|
| `title` | название темы — заголовок страницы и листов |
| `description` | описание для поисковиков и превью ссылки |
| `kicker` | строка над заголовком: «8 класс · Макарычев и др. · Алгебра» |
| `lead` | подзаголовок стартового экрана |
| `modeBoard`, `modePrint`, `modeHome` | тексты карточек режимов на стартовом экране |
| `printTitle`, `homeTitle` | заголовки раздатки и тренажёра |
| `homeIntro` | текст над выбором раздела в тренажёре |

### topic.js — что тема обязана объявить

Сборка проверяет, что всё это есть, и не соберёт тему без них.

| Объявление | Что это |
|---|---|
| `const CONFIG` | параметры, которые учитель может поменять: `board.previewDelay`, `print.{variants, traps, space}`, `home.{round, points[], hintPenalty, maxMultiplier}` и свои |
| `const GEN_VERSION` | версия генератора — первая часть номера варианта «1-4817» |
| `const TYPES` | типы заданий (ниже) |
| `const CATS` | типы ошибок для «Над чем поработать»: `{ код: [название, совет] }` |
| `const SECTIONS` | разделы тренажёра: `{ title, text, types: [...], ex() }` |
| `const KINDS_V1` | состав варианта раздатки: `[тип]`, `[тип, форма]` или `[тип, [формы]]` |
| `const WORDS_V1` | слова для кодового слова: столько букв, сколько заданий, буквы не повторяются |
| `const PRINT` | тексты листа: `instr` (ученику), `about` и `ogeAbout` (учителю под кнопками печати) |
| `function boardExample(random, old)` | пример для доски: `false` — из `CONFIG.board`, `true` — «Другие числа» |
| `function buildSteps(e)` | шаги доски для примера `e` |
| `const BOARD` | `{ previewUntil, poster }` — до какого шага крутится превью и какой шаг снимать на картинку |

Необязательно:

| Объявление | Что это |
|---|---|
| `const OGE_V1` + `function ogeTask(kind, rnd)` | бланк ответов как в ОГЭ: состав и задание `{ kind, t, ask, ans }`, `ans` — число строкой |
| `function helpInit()` | дорисовать формулы в справке (дроби, корни) |
| `const TOPIC_INPUTS` | свой вид ввода ответа: `{ имя: { html(t), collect(get) } }` |

### Тип задания

```js
sum: {
  input: 'num',                    // num | frac | choice | eq | est | свой из TOPIC_INPUTS
  gen: (rnd, form) => ({ ... }),   // задание из зерна — никакого Math.random()
  bad: t => ...,                   // вырожденные случаи: true — сгенерировать заново
  text: t => '...',                // запись задания (HTML)
  ans: t => Q(...),                // ответ: число {n, d} для num/frac, строка для choice
  ok: t => '...',                  // короткое объяснение верного ответа
  wrong: (t, x) => bad('код', '...'),  // объяснение ошибки с вычислением; типичная — по имени
  hints: t => ['...', '...'],      // две подсказки: общая и почти ответ
  traps: t => [{ key, html }],     // ответы-ловушки для таблицы букв — на типичных ошибках
  // необязательно: options (для choice), key/keyHTML (запись ответа в ключе),
  // ask (вопрос в тренажёре), sheet (формулировка на листе), answer (ответ в разборе ошибки), same
}
```

Готовые функции ядра: случайные `int`, `pick`, `shuffle`, `mulberry32`; точные дроби `Q`, `qadd`, `qsub`,
`qmul`, `qeq`, `qneg`, `gcd`, `isqrt`, `qsqrt`, `floorSqrt`, `toMixed`, `decStr`; запись `F` (дробь этажом),
`M` (смешанное число), `RT` (корень), `X` (курсивный x), `htmlQ`, `keyQ`, `esc`, `plural`, `MINUS`;
чертежи `tx`, `grid`, `under`, `svgFrac`, `numLine`, `sr`, `ds`. Пример всего этого — тема
`materials/arifmeticheskii-kvadratnyi-koren/`.

## 4. Проверки

`npm test` в конструкторе — **тест-контракт** для каждой темы:

- открывается во всех режимах без ошибок, ссылка «Назад на сайт», ссылка для учеников — только тренажёр;
- тема описана полностью: у каждого типа есть генератор, проверка, объяснение, подсказки;
- раздатка: 30 вариантов различны, номер восстанавливает вариант, буквы ключа складываются в слово;
- бланк ОГЭ (если есть): ответы — числа, которые помещаются в клеточки;
- доска: все шаги вперёд и назад на 15 разных примерах, кадр для превью;
- тренажёр: в каждом разделе верные ответы принимаются, неверные объясняются с вычислением;
- работает без localStorage;
- **замороженные варианты**: если для темы есть снимок `tests/snapshots/<slug>.frozen.json`, собранный
  материал обязан давать ровно те же варианты раздатки.

Тест темы на сайте (`tests/<slug>.test.mjs`) проверяет главное, чего не может знать конструктор:
**ответы, посчитанные независимо** от кода материала.

## 5. Важные правила

- **Собранный файл руками не правим.** Вверху файла это написано. Правим тему или ядро и пересобираем.
- **Напечатанные листы должны давать прежние ответы.** Когда тема опубликована, сними снимок вариантов:

  ```bash
  npm run snapshot -- <slug>
  ```

  Дальше тест следит, чтобы варианты не менялись. Нужно изменить генератор или состав раздатки —
  увеличь `GEN_VERSION` и сохрани старую ветку генератора, пока на неё есть листы, затем обнови снимок.
- **Изменил ядро — пересобери все темы:** `npm run build -- --all`, затем `npm test` и проверки на сайте.
- Правила содержания материалов (математическая запись, методика, ловушки на типичных ошибках, печать) —
  в `AGENTS.md` сайта, разделы 5 и 7, и в `docs/FORMATS.md`, `docs/TECH.md` сайта.

## 7. Команды — коротко

| Команда | Что делает |
|---|---|
| `npm install` | один раз: поставить jsdom для проверок |
| `npm run new -- <slug> --title "Название"` | заготовка новой темы и карточки на сайте |
| `npm run build -- <slug>` | собрать тему в сайт (`--all` — все темы, `--site <папка>` — другой сайт) |
| `npm test` | тест-контракт и замороженные варианты |
| `npm run snapshot -- <slug>` | снять снимок вариантов опубликованной темы |
